## 二、人工浏览器走查清单（需要有浏览器的环境，预计 20 分钟）

启动：
1. 后端：`cd cloudnote-modern/backend && mvn spring-boot:run`（或 java -jar，端口 8081，MySQL 需就绪）
2. 前端：`cd cloudnote-modern/frontend-web && npm install && npm run dev` → http://localhost:5173

### 游客端
- [ ] `/shares` 打开：顶部导航「云笔记/分享广场/社区活动」，右侧登录/注册按钮
- [ ] 搜索关键字（如“Spring MVC”）结果分页正常；点标题右侧显示详情（分享者+富文本）
- [ ] 点「收藏该分享」→ 提示登录并跳转登录页
- [ ] `/activities` 卡片列表 → 点进详情：投稿列表可翻页、可看详情；点顶/踩/收藏/参加 → 引导登录

### 普通用户
- [ ] 注册新账号 → 登录 → 跳转 `/notes`
- [ ] 新建笔记本/笔记 → 编辑保存 → 分享 → 顶部搜索能看到自己分享
- [ ] 收藏分享后在「收藏笔记本」能看到；回收站删除/恢复/彻底删除；活动投稿出现在「活动投稿」
- [ ] 移动端宽度（浏览器窗口缩窄或手机模式）下三栏布局自动堆叠可用

### 管理员
- [ ] admin 登录 → 自动跳 `/admin`；左侧（标签页）五类管理均可进入
- [ ] 用户管理：搜索/停用（该用户再登录被拒）/启用/提升/删除
- [ ] 分享管理：下架某分享后刷新 `/shares` 不可见，上架恢复
- [ ] 活动管理：发布→广场可见；删除后投稿清理
- [ ] 数据备份：点击后提示完成，`backend/backup/cloudnote_*.sql` 存在

### 兼容性
- [ ] 与旧系统并存：旧系统 8080 独立启动不受影响；同一 MySQL 数据可分别验证
- [ ] 移动端：上述主要页面在 ≤480px 视口下均可操作
